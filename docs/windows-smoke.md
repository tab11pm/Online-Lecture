# Windows packaged smoke

**Статус:** Windows-артефакт ещё не собран и не запускался на Windows. Пункты ниже
выполняются вручную на чистой Windows x64 VM без Node.js, npm и репозитория.
Успешные Linux unit/build-гейты не заменяют этот чек-лист.

## Подготовка

1. Собрать на Windows x64: `npm run dist:win -w @online-lecture/desktop`.
2. Записать SHA-256 из `apps/desktop/dist/OnlineLecture-Setup-<version>-x64.exe.sha256`.
3. Скопировать только `.exe` и `.sha256` на чистую VM. Убедиться, что Node.js/npm,
   Chromium и репозиторий отсутствуют.
4. Для fake-сценариев использовать отдельный временный `LOCALAPPDATA`; реальные
   SSO/BBB в автоматический smoke не входят.

## Установка и identity

- [ ] Установка проходит без UAC; каталог — per-user, ярлык запускает
      `OnlineLecture.exe`.
- [ ] SmartScreen предупреждает о неподписанном тестовом `.exe`; защита Windows не
      отключается.
- [ ] Повторная установка поверх работает; версия и файлы обновляются.
- [ ] Второй запуск при уже открытом приложении не создаёт второй worker и открывает
      существующее окно.
- [ ] Запуск с `--hidden` не создаёт второе окно и не дублирует worker.
- [ ] В Диспетчере задач после «Выход» не остаются процессы worker/браузера.

## Fake-session runtime

- [ ] `ONLINE_LECTURE_PACKAGED_EXECUTABLE=<путь к OnlineLecture.exe>` и
      `CI_ELECTRON_E2E=1` запускают четыре существующих E2E именно на упакованном exe.
- [ ] `app.isPackaged === true`; fake вход, импорт, лекция, остановка и журнал
      работают с временным `LOCALAPPDATA`.
- [ ] Добавление, перенос и удаление пары работают на упакованных ресурсах.
- [ ] Рядом с exe/в рабочем каталоге лежит подложный `.env` с sentinel-переменной:
      она не попадает в окружение MCP и не меняет stdout протокола.
- [ ] Переменные `NODE_PATH`, `NODE_OPTIONS`, `ELECTRON_RUN_AS_NODE` и developer
      CLI-пути не нужны для запуска; приложение не ищет системный Node.js.

## Браузеры и сессия

- [ ] По умолчанию выбран Edge; вход и импорт не требуют скачивания браузера.
- [ ] Кнопка установки Chromium запускает распакованный Playwright CLI через Electron
      Node, без системного Node.js.
- [ ] Ошибка/повтор загрузки Chromium показываются в UI; успешный выбор сохраняется
      и одинаково применяется к SDO MCP, импорту и BBB.
- [ ] При недоступном DPAPI пароль не сохраняется fallback-механизмом.
- [ ] Реальная разрешённая учётная запись: вход, импорт расписания и тестовая лекция
      (отдельная ручная проверка, не часть автоматического smoke).

## Трей, уведомления, автозапуск

- [ ] Трей открывает окно; уведомление о завершении/ошибке открывает журнал.
- [ ] Автозапуск по умолчанию выключен; после явного включения появляется значение
      `Online Lecture` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- [ ] После выключения автозапуска значение удаляется, чужие Run-значения остаются.

## Обновление и удаление

- [ ] Перед обновлением сохранить fixture-настройки, историю журнала и постороннее
      тестовое значение Run; после обновления данные и постороннее значение на месте.
- [ ] Удаление сохраняет `%LOCALAPPDATA%/OnlineLecture` и общий кэш Playwright.
- [ ] Uninstaller удаляет только собственный autostart и ярлыки.
- [ ] Завершённая активная fake-лекция не оставляет worker/браузер.
- [ ] Переустановка после удаления работает.

## Результат

Записать дату, версию Windows, SHA-256, выполненные и непройденные пункты. Не отмечать
пункт выполненным без фактического запуска на Windows.
