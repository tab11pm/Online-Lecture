# Выбор и установка Chromium в десктопном приложении — дизайн

**Дата:** 2026-10-15  
**Статус:** на ревью  
**OpenSpec:** `openspec/changes/chromium-choice-install`

## Цель

Пользователь Windows может выбрать Chromium вместо Edge и установить нужный браузер кнопкой в приложении, без терминала. Выбранный браузер последовательно используется для входа в ТУСУР через SDO MCP, импорта расписания и открытия лекции BBB.

## Текущее состояние

- На Windows десктоп задаёт `SDO_BROWSER_CHANNEL=msedge` для SDO MCP, если переменная отсутствует.
- Импорт расписания и BBB запускают Playwright Chromium без канала; без установленного браузера они завершаются ошибкой.
- Настройки приложения сохраняют только автозапуск и логин. Установщика Chromium и экрана выбора браузера нет.

## Решение

### Выбор браузера

На экране входа и после входа показывается настройка «Браузер для автоматизации»: «Edge (Windows)» и «Chromium». На Windows по умолчанию остаётся Edge, чтобы не требовать скачивания для входа. Настройка хранится в `settings.json` как узкий enum `edge | chromium`; на других платформах по умолчанию используется Chromium. Явно заданный разработчиком `SDO_BROWSER_CHANNEL` имеет приоритет для MCP и обозначается в интерфейсе как внешняя настройка; пользовательский выбор не должен создавать ложное впечатление, что переопределил её.

Настройка применяется к новым запускам браузера: `msedge` для Edge и отсутствие `channel` для Playwright Chromium. Рабочие браузерные сессии не прерываются при смене выбора. Десктоп передаёт выбор worker через типизированную команду; при следующем запуске приложения выбор читается до запуска worker. Сохранённая SSO-сессия и задания не удаляются.

### Проверка и установка Chromium

Перед сохранением выбора Chromium приложение проверяет существование исполняемого файла текущей версии Playwright (`chromium.executablePath()`). Если его нет, интерфейс предлагает кнопку «Установить Chromium». Основной процесс запускает CLI из установленного пакета `playwright` с фиксированными аргументами `install chromium` через встроенный Node Electron (`ELECTRON_RUN_AS_NODE=1`), без системного `npm`, `npx` или shell. Для упакованного приложения CLI и необходимые файлы Playwright должны быть доступны вне `app.asar`.

Установка может занимать время: интерфейс показывает состояния «не установлен», «загрузка», «установлен», «ошибка» и текстовый ход процесса. Повторное нажатие во время загрузки не создаёт второй процесс. Успех подтверждается повторной проверкой `executablePath()`, а не только кодом выхода. При ошибке браузер не выбирается; пользователю показывается понятное сообщение и возможность повторить. В режиме разработки дополнительно показывается копируемая команда `npx playwright install chromium`; пользователь установленной программы обходится без неё. Пароли, cookies и URL лекций в вывод установки и ошибку не попадают.

### Единое применение выбора

Настройка передаётся через типизированный контракт в main/worker и в опции запуска браузера для ядра. SDO MCP получает `SDO_BROWSER_CHANNEL=msedge` для Edge либо пустое значение для Chromium; импортер и BBB получают соответствующий Playwright `channel`. CLI сохраняет текущий режим и не зависит от настроек Electron. Main проверяет доступность выбранного Chromium до команд входа; ядро проверяет её до импорта и запуска BBB. Если браузер исчез после выбора, приложение сообщает об этом и предлагает установку; ошибка не должна выглядеть как неверный пароль или сломанная страница.

## Границы и упаковка

Chromium не включается в Windows-установщик: загрузка начинается после явного нажатия кнопки. Папка браузера находится в пользовательском профиле Playwright и переживает обновление приложения; если новая версия Playwright требует другой бинарник, проверка снова предложит установку. В фазе упаковки проверяется запуск CLI из `app.asar.unpacked` и загрузка на чистой Windows без Node.js. Удаление скачанного Chromium из интерфейса не входит в задачу.

Выбран вариант установки кнопкой. Простое отображение команды оставляет терминал в пользовательском сценарии; включение Chromium в установщик увеличивает его размер для всех пользователей, включая тех, кто оставит Edge.

## Проверка

- Настройки: значение по умолчанию, сохранение выбора, повреждённое значение, приоритет внешнего `SDO_BROWSER_CHANNEL`.
- Установщик: установленный/отсутствующий бинарник, один процесс на несколько нажатий, ошибка загрузки, успех без бинарника, повторная попытка, редакция ошибки.
- Сквозные контракты: выбранный канал для SDO MCP, импорта и BBB; отсутствие Chromium показывает установку до операции; CLI работает как раньше.
- UI: выбор, состояние загрузки, успех, ошибка и повтор, сохранение выбора после перезапуска.
- Ручная проверка на чистой Windows: установить приложение, выбрать Chromium, скачать кнопкой, войти, импортировать расписание и открыть тестовую лекцию.
- Сборка проверяет, что SDO MCP и десктоп используют совместимую версию Playwright, чтобы установленный Chromium подходил обоим.

## Риски

- Для скачивания нужен доступ к CDN Playwright. Ошибка сети остаётся на экране с повтором.
- Версия Chromium связана с версией Playwright; обновление зависимости может потребовать новой загрузки.
- Если разработчик явно задал `SDO_BROWSER_CHANNEL`, SDO MCP может использовать другой браузер. Интерфейс должен ясно показывать это переопределение.
