# Proposal

## Why

Сейчас каждая лекция добавляется вручную: пользователь сам ищет курс, указывает дату или дни недели и время. Для нетехнического студента это долго и легко ошибиться. Расписание группы уже опубликовано на `timetable.tusur.ru`, признак «реализуется в ЭИОС» выделяет онлайн-пары, а `course_links` связывает дисциплину с курсом SDO. Автоимпорт убирает ручную работу и делает первый запуск самодостаточным.

## What Changes

- Добавить вход через общий SSO `profile.tusur.ru` в onboarding и локальное зашифрованное хранение пароля (DPAPI на Windows).
- Добавить `TimetableClient` и парсеры: авторизованная главная, поиск группы, страницы недель и онлайн-пары по признаку «реализуется в ЭИОС».
- Сопоставлять дисциплину с курсом SDO через `course_links` и разрешать BBB-активность существующим MCP `resolve_online_lecture`.
- Добавить третий вид расписания `imported` с вхождениями по датам и флагами `edited`/`suppressed`.
- Расширить `Job` полями `source` (`manual`/`timetable`) и `origin`; авто-id `tt:<faculty>:<group>:<sdoCourseId>`.
- Реализовать слияние при обновлении: правки и скрытые вхождения сохраняются, ручные задания не изменяются.
- Добавить ручные пары «разово»/«каждую неделю» и действие «Перенести».
- Добавить CLI-команду `import` и Playwright-адаптер авторизованной выборки для ручного smoke-теста.

## Capabilities

### New Capabilities

- `timetable-import`: поиск группы, парсинг онлайн-пар, сопоставление с курсом SDO, резолв BBB и слияние расписаний.
- `onboarding`: вход через SSO по логину и паролю, прогресс авто-импорта, результат и локальное хранение пароля.
- `schedule-model`: тип `imported`, источник задания, флаги `edited`/`suppressed`, ручные пары и «Перенести».

## Impact

Изменение затрагивает ядро расписания и хранилище (новый тип `Schedule`, поля `Job`), добавляет пакет `src/timetable/` и CLI-команду `import`. Реализация фаз 1–2 не включает SSO-вход, Electron UI, трей и Windows-упаковку — для них предусмотрены отдельные планы. Интеграция с ТУСУР и MCP проверяется только на обезличенных фикстурах, без живых вызовов в тестах.
