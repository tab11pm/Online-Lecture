# Spec Delta

## Purpose

Обеспечивает локальное и устойчивое хранение расписаний и истории запусков без отдельной установки базы данных пользователем.

## ADDED Requirements

### Requirement: Инициализация и миграции хранилища

Система SHALL автоматически создавать локальную SQLite-базу при первом запуске и SHALL применять версионированные миграции до выполнения операций с заданиями.

#### Scenario: Первый запуск
- **WHEN** файл базы данных отсутствует
- **THEN** система создаёт пригодную для работы базу с актуальной версией схемы

### Requirement: Восстановление после повреждения

Система SHALL не перезаписывать повреждённую базу молча, SHALL перемещать её в диагностическую копию и SHALL пытаться восстановить расписание из последней пригодной резервной копии.

#### Scenario: Есть пригодная резервная копия
- **WHEN** открытие основной базы определяет её повреждённой и резервная копия доступна
- **THEN** система восстанавливает расписание и сообщает результат операции

#### Scenario: Резервной копии нет
- **WHEN** повреждённая база не имеет пригодной резервной копии
- **THEN** система сохраняет диагностическую копию и создаёт пустую новую базу
