# Spec Delta

## Purpose

Определяет запуск разовых и еженедельных лекций в заданном часовом поясе и не допускает повторного запуска одного события.

## ADDED Requirements

### Requirement: Планирование occurrence

Система SHALL вычислять occurrence для разовых и еженедельных заданий по их `timezone`, `joinAt` и `leaveAt`.

#### Scenario: Поздний запуск в активном окне
- **WHEN** планировщик запущен после `joinAt`, но до `leaveAt`
- **THEN** он создаёт или продолжает текущее occurrence немедленно

#### Scenario: Окно уже завершилось
- **WHEN** планировщик обнаруживает occurrence после `leaveAt`
- **THEN** он не начинает подключение и сохраняет запуск со статусом `skipped`

### Requirement: Единственность запуска

Система SHALL идентифицировать запуск парой `jobId + occurrenceId` и атомарно запрещать второй запуск такой пары.

#### Scenario: Повторная проверка того же события
- **WHEN** планировщик или CLI снова запрашивает уже созданное occurrence
- **THEN** система не создаёт второй запуск
