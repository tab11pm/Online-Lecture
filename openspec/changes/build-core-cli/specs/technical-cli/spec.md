# Spec Delta

## Purpose

Предоставляет разработчику технический CLI для проверки конфигурации и управления локальным ядром без UI и внешней автоматизации.

## ADDED Requirements

### Requirement: Проверка YAML-конфигурации

Команда `config validate` SHALL проверять технический YAML разовых и еженедельных заданий и SHALL отклонять базовый URL `https://bbb2.tusur.ru/html5client/` как не являющийся ссылкой конкретной Moodle BBB-активности.

#### Scenario: Базовый BBB URL
- **WHEN** YAML содержит базовый URL BBB как `target.url`
- **THEN** команда завершается с ошибкой валидации без создания задания

### Requirement: Команды управления заданиями

CLI SHALL предоставлять `jobs list`, `run` и `run-once <job-id>`; `run-once` SHALL сохранять исходный `leaveAt` выбранного occurrence.

#### Scenario: Ручной запуск задания
- **WHEN** пользователь запускает `run-once` для существующего задания в допустимом временном окне
- **THEN** система создаёт не более одного соответствующего occurrence с неизменённым deadline

### Requirement: Неподключённая авторизация SDO

Команда `auth check` SHALL сообщать, что адаптер SDO MCP не подключён, пока этот адаптер не добавлен отдельным изменением.

#### Scenario: Проверка до интеграции MCP
- **WHEN** пользователь выполняет `auth check` в первом change ядра
- **THEN** команда не сообщает успешную авторизацию и возвращает понятный статус отсутствующего адаптера
