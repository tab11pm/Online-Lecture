# Proposal

## Why

Десктопное приложение после входа ничего не делает: импорт расписания и посещение лекций доступны только через CLI. По `SPEC.md` пользователь Windows должен один раз войти, а дальше приложение само находит онлайн-пары и заходит на лекции в фоне.

## What Changes

- Вынести конвейер импорта из CLI в сервис ядра с прогрессом и транзакционной записью.
- Запускать в процессе ядра импорт по расписанию и фоновый планировщик лекций на основе `JobRunner`.
- Добавить главное окно: текущая и ближайшая лекция, список пар, итог импорта, «Остановить», «Пропустить/Вернуть».
- Показывать состояние и «Остановить лекцию» в трее; реагировать на сон, пробуждение и выход во время лекции.
- Добавить настройку «Показывать окно лекции».

## Capabilities

### New Capabilities

- `desktop-lectures`: автоимпорт расписания, фоновое посещение лекций и управление ими в десктопном приложении.

### Modified Capabilities

<!-- Нет: правила импорта CLI и жизненного цикла лекции не меняются. -->

## Impact

Затрагивает `src/timetable` (сервис импорта), `src/persistence` (транзакционная замена заданий), `src/core` (повестка), worker, main, preload и renderer десктопа, а также CLI `import` (переход на общий сервис без изменения вывода).
