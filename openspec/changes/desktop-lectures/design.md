# Design

## Context

Согласованный дизайн: [2026-10-15-desktop-lectures-design.md](../../../docs/superpowers/specs/2026-10-15-desktop-lectures-design.md).

## Goals / Non-Goals

**Goals:** после входа приложение само импортирует онлайн-пары, посещает лекции в фоне и даёт остановить или пропустить пару из окна и трея.

**Non-Goals:** правка времени, «Перенести», ручные пары, уведомления и журнал, упаковка.

## Decisions

- Планировщик, импорт, SQLite и активные запуски живут в worker; main — ретранслятор, трей, `powerMonitor`, настройки.
- Импорт: после входа, при запуске (старше 24 ч), раз в сутки, по кнопке; во время лекции откладывается; после ошибки повтор не чаще раза в час.
- Частичный импорт сохраняет найденные пары без удаления старых; полный — синхронизирует.
- Одна лекция одновременно; остановка — через `AbortSignal` жизненного цикла.
- UI получает целиковый снимок без URL и секретов.

## Risks / Trade-offs

- BBB-адаптер распознаёт только состояние «подключён» до появления фикстур реальных страниц.
- Падение worker во время лекции не возобновляет то же вхождение.
