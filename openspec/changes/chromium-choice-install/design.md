# Design

## Context

Согласованный дизайн: [2026-10-15-chromium-choice-install-design.md](../../../docs/superpowers/specs/2026-10-15-chromium-choice-install-design.md).

## Goals / Non-Goals

**Goals:** пользователь выбирает Chromium и устанавливает его внутри Windows-приложения; один выбор применяется ко всем браузерным операциям.

**Non-Goals:** включение Chromium в установщик, удаление браузера, изменение поведения CLI.

## Decisions

- Хранить выбор как enum `edge | chromium` в настройках пользователя.
- Считать установленным только бинарник, доступный текущей версии Playwright.
- Запускать установленный CLI Playwright с фиксированными аргументами, без shell и системного Node.js.
- Сохранять выбор Chromium после успешной установки. Во время загрузки и при ошибке текущий браузер не менять.
- Явное `SDO_BROWSER_CHANNEL` сохраняет приоритет для разработки и показывается в UI как переопределение.

## Risks / Trade-offs

- Загрузка требует сети и может повториться после обновления Playwright.
- Упаковка должна обеспечивать запуск CLI из `app.asar.unpacked`; это требует Windows-проверки без установленного Node.js.
