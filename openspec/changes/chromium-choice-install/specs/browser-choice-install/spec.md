# Spec Delta

## Purpose

Определяет выбор браузера и установку Chromium в Windows-приложении без терминала.

## ADDED Requirements

### Requirement: Выбор браузера

Десктопное приложение SHALL предлагать пользователю Edge и Chromium, сохранять выбор и применять его ко всем новым запускам браузера в SDO MCP, импорте расписания и BBB. На Windows до выбора пользователя SHALL использоваться Edge.

#### Scenario: Пользователь выбрал Chromium
- **WHEN** Chromium текущей версии Playwright установлен и пользователь выбирает Chromium
- **THEN** выбор сохраняется, а новые операции SDO MCP, импорта и BBB запускают Chromium

#### Scenario: Пользователь выбрал Edge
- **WHEN** пользователь выбирает Edge
- **THEN** новые операции SDO MCP, импорта и BBB запускают канал `msedge`

#### Scenario: Внешнее переопределение
- **WHEN** разработчик задал `SDO_BROWSER_CHANNEL` в окружении, включая пустую строку
- **THEN** приложение не перезаписывает это значение для SDO MCP и показывает переопределение в интерфейсе

### Requirement: Установка Chromium внутри приложения

Десктопное приложение SHALL проверять наличие основного Chromium и Chromium headless shell для установленной версии Playwright и SHALL предоставлять кнопку установки без требования системного Node.js, npm или терминала. Установка MUST запускаться только после действия пользователя.

#### Scenario: Браузер отсутствует
- **WHEN** пользователь выбирает Chromium, а нужного исполняемого файла нет
- **THEN** приложение предлагает «Установить Chromium» и не сохраняет недоступный выбор

#### Scenario: Установка выполнена
- **WHEN** процесс установки завершился и исполняемый файл найден
- **THEN** приложение показывает успех и сохраняет выбор Chromium

#### Scenario: Установка не выполнена
- **WHEN** загрузка или проверка браузера завершилась ошибкой
- **THEN** приложение показывает ошибку и кнопку повторной попытки, сохраняя прежний выбор браузера

#### Scenario: Повторное нажатие
- **WHEN** установка уже выполняется и пользователь нажимает кнопку ещё раз
- **THEN** второй процесс установки не запускается

### Requirement: Объяснение отсутствующего браузера

Десктопное приложение SHALL до входа, импорта или открытия лекции сообщать, что для выбранного Chromium требуется установка, вместо сообщения о неверном пароле или ошибке страницы.

#### Scenario: Chromium удалён после выбора
- **WHEN** сохранён Chromium, но его исполняемый файл отсутствует
- **THEN** приложение показывает предложение повторной установки до следующей браузерной операции
