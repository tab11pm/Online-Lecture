# Design

Полный архитектурный дизайн: [Уведомления и журнал десктопа](../../../docs/superpowers/specs/2026-10-19-desktop-notifications-journal-design.md).

## Decisions

- История запусков читается из `runs`; отдельные безопасные события хранят ошибки и ключи подавления повторов.
- Worker создаёт события при переходах состояния, main показывает уведомление только для нового ID события.
- Renderer получает постраничную модель журнала с безопасными полями через узкий IPC.
- Диагностический `core.log` не служит источником пользовательского журнала.

## Risks

- Обрыв между сохранением запуска и события: запуск остаётся в `runs`, недостающее событие восстанавливается без старого уведомления.
- Внешние названия могут содержать секретные фрагменты: редакция применяется перед сохранением и передачей.
- Системные уведомления могут быть отключены Windows: отказ показа не блокирует ядро и запись истории.
