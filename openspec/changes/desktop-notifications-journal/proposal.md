# Proposal

## Why

Приложение уже запускает лекции и хранит их состояния, но пользователь видит только последний запуск в главном окне. При свёрнутом окне он не узнаёт о необходимости повторного входа и ошибках. `SPEC.md` §10 требует системные уведомления и понятный локальный журнал.

## What Changes

- Добавить историю запусков и ошибок, доступную после перезапуска.
- Показывать системные уведомления для указанных в `SPEC.md` событий без повторов от обновления снимка.
- Добавить раздел «Журнал» с фильтром ошибок и постраничной загрузкой.
- Передавать в UI и уведомления только безопасные типизированные данные.

### New Capabilities
